# onnxruntime-mirror

Mirror of the `microsoft/onnxruntime` v1.29.1 release assets, after the upstream
GitHub repository became unreachable (returning 404 on the web UI, API, raw
content, and git protocol) starting around 2026-11-18, with no official
explanation or restoration as of this writing.

Files here are byte-identical to the original release assets - verified by
SHA256 against hashes pinned before the outage - redistributed under
ONNX Runtime's own MIT license (see the LICENSE file inside each archive).
